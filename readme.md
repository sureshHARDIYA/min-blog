## Built with

Next.js, React, TypeScript and Tailwind CSS, deployed on Vercel.

## Run it locally

You need Node.js 18 or newer and pnpm 10.

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

Then open `http://localhost:3000`.
